# Map location and operating-status audit

This desk review covers healthcare, bus stops and education destinations in the Greater Malé map. The sections distinguish mapped coordinates, institutional identity, operating-status evidence and suitability for each access goal. A catalogue entry or plausible road attachment alone does not verify current physical operation.

## Healthcare review

Healthcare reviewed **10 October 2026** against baseline `greater-male-2026-10-10-ad35f36a6a`. The machine-readable overlay is [`data/public/healthcare-location-audit.json`](../data/public/healthcare-location-audit.json), version `healthcare-review-2026-10-10-1ce8415f02`. It covers all **13 mapped hospital/clinic records**, with source URLs, retrieval timestamps, file hashes, registry identities, care scope, and separate coordinate evidence. Raw public-source captures are under `data/raw/facility-audit/`.

The audit supports **8 default general-care destinations**, **1 open facility whose current broad public eligibility is unverified**, **3 unverified mapped sites**, and **1 explicitly closed clinic**. “Open” means current registry, provider or operator evidence on the review date. It does not establish opening hours at the selected scenario time, available appointments, emergency capability, capacity, affordability, or an accessible entrance.

## Coordinate and freshness limits

The original preparation pipeline matched normalized official names and OSM categories, without parsing closed status. It could therefore retain a closed clinic, miss Medica's official type, and conflate identically named registrations. This overlay resolves status and identity separately from geometry.

Coordinates remain OSM points or building centroids. Three operator-linked map destinations corroborate the mapped campus area. Distances above use actual `!3d`/`!4d` place coordinates, or the operator-selected ADK target, **not** Google Maps viewport centres. Embedded-map centres are not accepted as replacement coordinates. No destination has a surveyed accessible street entrance in this bundle; no new coordinate has been invented.

HEMS displayed practitioner totals are not service capacity: zero does not prove closure. The dated Ministry private-facility PDF is address evidence from February 2026, not a live status feed. Each named Aasandha suspension/termination search was also captured; no exact mapped-provider row was identified. Such absence is not used to infer that a site is open, and lifted suspensions must not be treated as current closure.

A primary June notice and current replacement coordinates were not recovered, so relocation remains a documented review lead; no point is added or moved.

**Vilimalé Hospital** appears in the current IGMH operator network, but the existing baseline has no verified geocoded hospital point there. Retain the coverage gap instead of inventing an island-centroid destination.

## Integration policy

Use `operatingStatus === 'open'`, `careScope === 'general'`, and existing map-verification checks for default general-care routing and destination markers. Keep all reviewed records inspectable in the catalogue with their status, review date and reason. An optional historical/unverified layer must not silently change the access metric. Include the audit file digest and all referenced source metadata in baseline version/provenance so a status-only update invalidates saved calculations appropriately.

This was a public-source desk review, not a visit or telephone confirmation. Clinics still lack scenario-time opening calendars. A successful journey means reaching a mapped general-care destination; it does not guarantee that an appointment or treatment is available on arrival.

They do not confirm signs, usable kerbs, shelters, wheelchair access, road-work conditions or physical active/closed status. **No stop received a field check or verified physical closure determination.** An operator listing and loaded departure provide narrower evidence than a currently usable boarding location.
