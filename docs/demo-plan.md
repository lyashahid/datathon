# Seven-minute demo plan

Everything below uses features that exist in the app. Numbers quoted are what the demo data
produces today (see `docs/metric-definitions.md`); say them as "in this demo data", and read them
off the screen rather than from memory.

**Setup (before going on stage)**

- `npm run dev` (or `npm run build && npm run preview`) and open the app full-screen at 1440×900 or larger.
- Click **Demo** (top bar) once, run to the end, then **Restart Demo**. This warms caches and
  proves the path. The guide (bottom-right of the map) drives every step with **Next**.
- Keep the inspector (right) and layer panel (left) open.

## Fallback demo path

The planning simulator is fully local; only the basemap tiles and the weather readout use the
network. Nothing in sections 1–8 depends on weather.

| Failure                      | What the app does                                                                       | What to do                                                                                                                                                                              |
| ---------------------------- | --------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Weather API down             | Top bar shows "Weather unavailable"; Rain/Wind/Marine views show "Forecast unavailable" | Skip the live-weather aside. The resilience section uses the **disruption presets**, which need no live data. Say: "Live weather is optional; resilience runs on explicit assumptions." |
| Basemap tiles unreachable    | Falls back through OpenFreeMap → CARTO → plain offline background with a notice         | Continue: islands, infrastructure, H3 cells and all analysis still render.                                                                                                              |
| No internet at all           | Same as above                                                                           | Run from `npm run preview` on the laptop; everything except tiles and weather works.                                                                                                    |
| A demo step reports an error | Guide shows the message and stays put                                                   | Click **Restart Demo** (replays from step 1 to a known state), then **Next** to the section you were on.                                                                                |
| Browser refresh mid-demo     | Scenarios are in memory and are lost                                                    | Click **Demo**: it recreates the demo scenario from scratch in a few seconds.                                                                                                           |
| Guide not wanted             | Close it (×); the map keeps its state                                                   | Continue manually: the same controls are highlighted in the steps above.                                                                                                                |

**Manual path (no guide):** Info Views (7) → Transport → click a red cell at Malé east →
Find Improvements → Find bus-stop locations → click badge 1 → Add to Scenario → Info Views → Impact →
Conditions → Severe Marine Disruption → Show change on map → Conditions → Normal → Compare.
