## Measured improvements

The production route module changed from **677,865 to 115,804 bytes**, an **82.9% reduction**. Its static JavaScript dependency closure changed from **780,078 to 333,645 bytes**. These measurements exclude the separately loaded active workspace, layout, MapLibre and workers; they are not a claim that the complete application download shrank by 83%. Cold-dashboard browser checks verify that seven unrelated workspace modules are not downloaded and planning/conditions/operations reads do not begin.

The installed national GeoJSON response contains **2,223 features**. The same data and SHA-256 were returned before and after the backend change. Median complete local response time changed from **1.374 to 0.642 seconds**. Backend gzip changes its transfer from **14,973,659 to 5,424,658 bytes** (63.8% smaller). The frontend proxy decompresses that hop and correctly strips the obsolete encoding/length headers; this does not claim compressed browser delivery.

An isolated interpolation benchmark using a retained 206-vertex bus route measured **77.42 to 1.93 ms for 10,000 samples**, with identical coordinates. This measures interpolation CPU work, not end-to-end frame rate.

## Verification

Final validation includes frontend formatting/lint, Svelte/TypeScript diagnostics, the production build, **60 frontend unit tests**, **568 backend tests**, and **67 browser checks with zero page errors**. Browser verification uses the real backend and provider responses on production port 5181. Transport failures and delayed delivery are used to exercise recovery/races; successful analytical payloads are not fabricated.

The browser receipts cover all eight main desktop/mobile workspaces, 390 × 844 layouts, on-demand loading, failed-asset recovery, retained filters/drafts, stable map pins, canceled route/evaluation requests, proposal placement and impact, journey playback, forecasts/backtests and frozen receipts, multi-dataset comparison and complete exports, live map points, provider route geometry, notice/advisory demand loading and keyboard inspector dismissal.

Run the focused audit with `npm run test:browser:audit` and `node scripts/verify-secondary-audit-browser.mjs`. Set `MOBILITY_QA_URL` to the production preview URL when running other browser suites. [Combined verification receipt](../artifacts/qa/code-visual-audit/verification.json) records the completed suites and source hashes.

## Remaining performance boundary

The browser still receives and parses the full 14.97 MB national geometry snapshot. A viewport-scoped/vector-tile data contract is the strongest next performance improvement for larger deployments. MapLibre remains a separately loaded vendor chunk above the build warning threshold. This audit preserves geometry fidelity and the current API contract, and does not suppress that warning or claim that every possible optimization is complete.

Provider gaps, dated passenger histories, modeled resident origins and scenario assumptions retain their existing source/uncertainty disclosures. Appearance and faster responses do not strengthen those underlying inputs.
