# Sea and airport source context

Published transport statistics and port records provide context alongside the map. They do not add operating services, change access scores, infer route demand or establish live vessel positions. The current collection inventory and preparation commands are in [nationwide source models](national-data-models.md).

| Source                                                                            | Retained interpretation                                                                                                                                                                                                                                                                                                                         |
| --------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [FollowMe public vessel directory](https://m.followme.mv/public/)                 | Dated directory/position evidence, distinct from the current bounded live adapter. Provider timestamps and reuse qualifications remain with records; private contacts, IMEI and raw device fields are excluded from browser output. See [terms](https://followme.mv/?pg=terms) and [issued-key API documentation](https://followme.mv/api/v1/). |
| [MPL vessel movements](https://port.mv/vessel-movements)                          | Arrival, departure, expected-arrival, shifting and at-port records. These have no geographic vessel positions. Old arrival dates or missing berths do not identify a ship's current location.                                                                                                                                                   |
| [MBS Statistical Yearbook 2026](https://statisticsmaldives.gov.mv/yearbook/2026/) | Published airport passenger and aircraft totals attributed to the source agency. Retain international/domestic, arrivals/departures, monthly/annual and airport coverage separately. Movements are not unique travelers, and annual totals must not be added to their component months.                                                         |
| [MACL Insights](https://macl.aero/insights)                                       | Investigated as an agency source; [terms](https://macl.aero/terms-of-service) restrict automated mirroring. Official downloadable yearbook tables support the shipped context; a direct agency integration requires its own permission.                                                                                                         |

Data Studio exposes prepared public collections through `/api/v1/datasets`. Source IDs, dates, hashes, units, missingness and transformation receipts travel with the records. Normalized national transport context also lives in `data/public/transport-context.json`; underlying acquisition archives are local and are not startup dependencies. Missing values stay unavailable rather than zero.

Neither airport aggregates nor port-call rows identify individual ferry departures, vessel-to-route assignments, route occupancy or local unmet demand. Geographic boat markers require actual reported positions. For current observations use [live feeds](live-map-feeds.md); for published ferry calendars and their pressure proxy use [official sea services](official-sea-services.md).
